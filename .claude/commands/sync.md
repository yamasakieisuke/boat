---
description: boat リポジトリの変更を commit & push（未pushコミットがあれば push のみ）
---

以下の手順でリポジトリを同期してください：

1. `git status` で変更を確認
2. 変更がある場合：
   - 機密情報（APIキー・トークン・パスワード等）が含まれていないか `.env` や新規ファイルをチェック
   - `git add -A`
   - 変更内容を要約した簡潔な日本語コミットメッセージで `git commit -m "..."`
3. `git push` を実行
4. 未コミット変更が無く、未push commitだけある場合はpushのみ実行
5. 最後に `git log --oneline -3` と `git status` で結果を確認

注意：
- `.env` 等の機密ファイルは既に `.gitignore` で除外されているが、新規ファイル追加時は再確認
- コミットメッセージは「何を変えたか」ではなく「なぜ変えたか」を意識
