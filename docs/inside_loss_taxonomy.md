# 1号艇の「負け方」の類型化と、頭を替えたときの成否（2026-08）

**目的**: 「1号艇を1着に予想したのに1号艇以外が1着になった」レースを負け方で類型に分け、
類型ごとに(a)事前の予兆があったか (b)買い目を変える／見送る判断に使えるか を回収率つきで判定する。
追補として、対称形の「1号艇以外を頭にして当たった／外した」も分析した。

**位置づけ**: `docs/race_development_research.md` の続き。前回の結論
（1号艇1着は AUC 0.70 で予測できるが3連単ROIは全十分位で約70%に張り付く／頭を替えても的中は上がらない）
は**再検証の上で前提として扱い、繰り返さない**。本稿は「負け方の中身」に踏み込む。

⚠️ **本稿は 2026-08-16 に全面修復された `data/results_csv` 上で行った。**
修復前のデータで書かれた過去の調査とは母数・欠損状況が異なる（§1.1）。

## 0. 要約

| # | 問い | 答え |
|---|---|---|
| 1 | 負け方は何種類あって、どんな割合か | 7類型に分類。最大は「3-4コースにやられた」37.1%、次に「出遅れ」23.2%、「差され」22.6%、「大外強襲」12.3%。**進入負け2.2%と1号艇消滅2.3%は合わせても4.5%しかない** |
| 2 | 類型ごとに予兆は読めるか | **読める度合いが大きく違う**。進入負けは AUC 0.801（敗戦内でも 0.754・リフト3.6倍）。対して**差され／まくり／大外は敗戦内 AUC 0.55前後＝ほぼ読めない** |
| 3 | 買い目が全滅するのはどの類型か | **進入負け ROI 0.0%（22R・的中ゼロ）と1号艇消滅 ROI 3.3%（28R）だけが全滅**。他の敗戦類型は抑え・穴が拾って20〜49%残る |
| 4 | その2類型を見送れば儲かるか | **ならない**。完全予知でも **+1.2pt（71.7%→72.9%）** が天井。母数が1.8%しかない |
| 5 | 買い目の構成を変えれば儲かるか | **ならない**。反実仮想シミュレーション（§5）で、どの事前スコア帯・どの構成でも**ROIが安定して75%を超えるセルは存在しない** |
| 6 | 頭を1号艇から替えたとき、当たり外れを事前に分けられるか | **予想エンジン自身の指標（gap・confidence・is_rough・スコア差）は完全に無情報**（t = −0.8〜+0.1）。一方、結果CSV由来の指標は分ける（t = 4〜6） |
| 7 | 「1号艇が負ける条件」と「非1号艇頭が当たる条件」は別物か | **同じ。1本の軸**。4群が P(1号艇が1着でない) で完全に単調に並ぶ（0.369 / 0.473 / 0.542 / 0.681） |

**もっとも実用的な単発の発見**: 現行エンジンが頭を1号艇から替えた374Rのうち、
**下位1/3の124Rは「1号艇が実際には66.9%勝つ」帯で替えている**（頭的中10.5%・ROI 43.6%）。
替える判断そのものが、替えるべき軸とほぼ無相関に発火している（§7.3）。

**そして全体としての答え**: 類型化しても回収率の改善余地は見つからなかった。
本稿の価値は「買い目を変えるべき類型はある」ではなく、**「無い、しかもその上限が +1.2pt だと数値で確定した」**ことにある。

## 1. データと検証設計

### 1.1 修復後データで判明した2つの構造（分析の土台）

`data/results_csv` 505ファイル / 454,544行 / **76,779レース**。

**(a) 欠損がほぼ消えた。** 修復前は `course_enter` が48〜50日分欠損し `venue_name` が195日分で
半数空欄だったが、修復後は **`course_enter` 欠損ゼロ・`venue_name` 欠損ゼロ・
(date,venue,race_no) の重複ゼロ**（修復前は枠番重複でレースを割る必要があった）。
**予想payload期間（2026-03-21〜05-17）と進入データが完全に結合できるようになった**のは今回が初めてで、
前回調査の制約4「payloadは `course_enter` 欠損期間と重なるため結合不能」は解消している。

**(b) 失格艇は「行が消える」形で記録されている。** `scripts/fetch_results.py:65` の `RE_RANK` は
着順を `(\d{2})` と2桁数字で要求するため、公式ファイルで着順が `Ｆ`／`失`／`転` になっている艇は
**正規表現にマッチせず、行ごと落ちる**。実際 `rank` 列は全行が 1〜6 の数値で、`st_timing` に
F表記は1件も無い。結果として：

- 6艇そろわないレース **4,999R**（6.5%）。うち **1号艇が欠けているのが917R**
- 残った艇の `course_enter` に**欠番があるか**で、消えた理由を2つに割れる
  - 欠番なし（1..k の順列）= レース前に消えた（欠場・出走取消）→ **110R**
  - 欠番あり = **その艇はコースを占めて発走した後に消えた**（F・失格・転覆・エンスト等）→ **807R**

つまり「事故類型」は間接的にだが**確実に検出できる**。ただし F と 転覆 と 失格 の区別はつかない。

### 1.2 特徴量の構築とリーク対策

選手特徴は**日付順に前進し、その日より前のレースだけ**で構築（同日のレースは互いに参照しない）。
縮約つき。`data/players/*.json` は現時点のスナップショットでリークするため使っていない。

| 特徴 | 定義 | 既出か |
|---|---|---|
| `w1_c1win` | 1号艇の選手の過去のコース1での1着率 | 既出 |
| `w1_st` / `out_st_best` / `st_adv_outer` | 通算平均ST と 2-6号艇の最速、その差 | 既出 |
| `mz_max` | 3-6枠選手の前づけ率（`course_enter < waku`）の最大値 | 既出 |
| `rival_win_best` | 2-6号艇のコース別1着率の最大 | 既出 |
| **`w1_late`** | **1号艇の選手が過去に「最速艇よりST 0.10秒以上遅い」発進をした率** | **新規** |

環境変数は 風速・波高・進入固定・会場・race_no（会場と race_no は **train期間だけで作った
ターゲットエンコード**でリークを断ってある）。

検証は時系列分割。主分割 **train: 2025-07-01〜2026-01-31 (32,446R) / test: 2026-02-01〜2026-08-15 (27,889R)**。
予想payloadに対する評価は **payload期間より前だけ（〜2026-03-20, 39,574R）で学習**して採点した。

再現性の確認として、本データでの P(1号艇1着でない) の test AUC は **0.699**、
進入が枠なりでないレースは **18.8%**・その1号艇1着率 **46.8%**（枠なりは57.2%）で、
いずれも前回調査（0.698 / 18.8% / 46.8% / 57.1%）と一致した。修復は本稿の結論を揺らしていない。

### 1.3 類型の定義（優先順に判定・排他）

| コード | 定義 |
|---|---|
| A 欠場・出走取消 | 1号艇の行が無く、残り艇のコースに欠番が無い |
| B 1号艇がレース中に消滅 | 1号艇の行が無く、残り艇のコースに欠番がある（F・失格・転覆・エンスト等） |
| C 進入負け | 1号艇が走ったが `course_enter ≠ 1` |
| D スタート出遅れ | 1コース発進だが、1号艇のSTが**最速艇より0.10秒以上遅い** |
| E 差され | 1コース発進・ST正常で、**勝者が2コース** |
| F まくり | 同上で、**勝者が3-4コース** |
| G 大外強襲 | 同上で、**勝者が5-6コース** |

> D の閾値0.10は恣意的である。**この定義だけは感度が高い**（§3.4）。

## 2. 負け方の類型と割合

全76,779R中、1号艇1着は 41,852R（54.5%）、**敗戦 34,927R（45.5%）**。

| 類型 | 件数 | 全体比 | 敗戦内比 | 勝者コース分布 (c1/c2/c3/c4/c5/c6) | 3連単中央配当 | 中央人気 |
|---|---:|---:|---:|---|---:|---:|
| A 欠場・出走取消 | 110 | 0.14% | 0.31% | 54.5 / 14.5 / 18.2 / 8.2 / 4.5 / 0.0 | 1,750 | 6 |
| **B 1号艇がレース中に消滅** | **807** | 1.05% | **2.31%** | 0.9 / 29.0 / 28.0 / 23.3 / 13.2 / 5.6 | 4,350 | 18 |
| **C 進入負け** | **752** | 0.98% | **2.15%** | **54.5** / 2.8 / 14.5 / 14.5 / 11.2 / 2.5 | 4,450 | 17 |
| **D スタート出遅れ** | **8,111** | 10.56% | **23.22%** | 0 / 24.3 / 25.4 / 29.1 / 15.7 / 5.5 | 7,170 | 26 |
| **E 差され（2c）** | **7,909** | 10.30% | **22.64%** | 0 / 100 / 0 / 0 / 0 / 0 | 3,770 | 13 |
| **F まくり（3-4c）** | **12,953** | 16.87% | **37.09%** | 0 / 0 / 58.0 / 42.0 / 0 / 0 | 5,490 | 20 |
| **G 大外強襲（5-6c）** | **4,283** | 5.58% | **12.26%** | 0 / 0 / 0 / 0 / 76.9 / 23.1 | **11,280** | **37** |
| Z その他 | 2 | — | 0.01% | — | — | — |
| （参考）1号艇1着 | 41,852 | 54.51% | — | 100 / … | 1,440 | 5 |

読み取り：

1. **「進入が乱れて1号艇が1コースに入れなかった」は敗戦のわずか2.15%。**
   1号艇が1コースに入れなかったのは全期間で852R（1.1%）だけで、その中身は
   2コースまで下げられた707R／3コース83R／4-6コース62R。**そして下げられた1号艇の1着率は11.7%**。
   起きると致命的だが、めったに起きない。
   （「進入が枠なりでない」レース18.8%とは別物であることに注意。外同士が入れ替わっても
   1号艇はほぼ1コースに入る）
2. **配当の階段がきれいに立っている。** 差され 3,770円 → まくり 5,490円 → 出遅れ 7,170円 →
   大外 11,280円。**中央人気で見ると 13番人気 → 20 → 26 → 37**。
   つまり「1号艇が飛ぶ」の中でも、**どの飛び方かで配当が3倍違う**。
   ここに構造があれば買い目に反映できる、というのが本稿の出発点だった。
3. **A（欠場）は事実上ノイズ。** 110Rしかなく、勝者コース分布が「1コース54.5%」と
   通常レースとほぼ同じ＝1号艇以外が欠けた5艇立てが多い。以降は扱わない。

### 2.1 出遅れ（D）は独立の類型ではなく、他の類型の「原因側」

D を除いて勝者コース分布を比べると：

| 1号艇のST | n | c2 | c3 | c4 | c5 | c6 |
|---|---:|---:|---:|---:|---:|---:|
| 普通（最速艇との差 < 0.10） | 25,145 | 31.5% | 29.9% | 21.7% | 13.1% | 3.9% |
| **遅い（≧ 0.10）** | 8,111 | **24.3%** | 25.4% | **29.1%** | **15.7%** | **5.5%** |

1号艇が出遅れると勝者が外へずれる（c2 −7.2pt、c4 +7.4pt、c5+c6 +4.2pt）。
方向は前回調査の `st_adv_outer` の結果（外のSTが速いと c4 が増える）と整合する。
**D は E/F/G と並ぶ横並びの類型ではなく、E/F/G の起こりやすさを動かす上流の状態**と読むのが正しい。

**もっとも高い配当を生む類型（G, 中央11,280円）が、もっとも読めない（AUC 0.583）。**
逆にもっとも読める類型（C, AUC 0.801）は発生率1%で、しかも§4で見るとおり買い目が全滅するだけの類型。

### 3.2 条件付き（「1号艇が負ける」ことは所与として、どの負け方になるか）

こちらが買い目構成の判断に直結する。敗戦レース12,513Rのみを母数にした one-vs-rest：

| 類型 | test件数 | 敗戦内比 | AUC | 最低十分位 | 最高十分位 | リフト | 上位寄与 |
|---|---:|---:|---:|---:|---:|---:|---|
| B 消滅 | 288 | 2.30% | 0.671 | 0.56% | 5.20% | 2.26 | **w1_late** |
| **C 進入負け** | 278 | 2.22% | **0.754** | 0.48% | 7.91% | **3.56** | 会場, **mz_max** |
| D 出遅れ | 2,900 | 23.18% | 0.599 | 13.59% | 35.89% | 1.55 | 会場, w1_late |
| **E 差され** | 2,879 | 23.01% | **0.554** | 17.43% | 28.22% | 1.23 | — |
| **F まくり** | 4,654 | 37.19% | **0.554** | 28.94% | 43.73% | 1.18 | — |
| **G 大外強襲** | 1,514 | 12.10% | **0.567** | 8.23% | 16.95% | 1.40 | 会場 |

**これが本稿の中心的な否定的結果である。**

> 1号艇が負けると分かっていても、**差されるのか・まくられるのか・大外に飛ばれるのかは事前にほぼ判別できない
> （AUC 0.554〜0.567、リフト1.2〜1.4倍）**。
> 一方で **進入負け（AUC 0.754・3.6倍）と消滅（0.671・2.3倍）は判別できる**が、
> この2つは敗戦の4.5%にすぎない。

前回調査は「1コース敗戦時の勝者コース分布は**気象条件**では動かない（§3.1）」と結論した。
本稿は同じ結論が**選手側の事前情報（コース別1着率・ST・前づけ率・出遅れ率）を全部入れても成り立つ**ことを
時系列検証で確認した、という関係にある。動かせるのは「飛ぶか」であって「どう飛ぶか」ではない。

### 3.3 新規に効いた特徴 `w1_late`（出遅れ率）

「1号艇の選手が過去に最速艇より0.10秒以上遅く出た率」は、既存の通算平均ST とは別に効く。
特に **B（消滅）の敗戦内予測では最大の寄与**（係数 +0.37、他を引き離す）。
機構としては「発進が不安定な選手は F・出遅れ・失格の分布の裾が厚い」と読める。
ただし**単独での効果量は小さく、Bの母数が1%であるため実用価値はほぼ無い**（§4）。

### 3.4 定義の感度（正直な限界）

D の閾値を動かすと類型の割合が大きく動く。**Dの23.2%という数字を単独で引用してはいけない。**

| ST差の閾値 | D 出遅れ | E 差され | F まくり | G 大外 |
|---|---:|---:|---:|---:|
| 0.06秒 | 45.6% | 16.8% | 24.8% | 8.0% |
| 0.08秒 | 32.2% | 20.3% | 32.2% | 10.5% |
| **0.10秒（採用）** | **23.2%** | **22.6%** | **37.1%** | **12.3%** |
| 0.12秒 | 17.1% | 24.1% | 40.6% | 13.5% |
| 0.15秒 | 9.2% | 25.8% | 45.0% | 15.3% |

E:F:G の相対比は閾値によらず安定している（およそ 1 : 1.6 : 0.5）。A/B/C の件数は閾値と無関係。

## 4. 類型ごとの回収率（予想payloadとの結合）

`output/wordpress/*/*_payload.json` × 修復後 `results_csv` = **3,156R（2026-03-21〜05-17）**、
うち**頭＝1号艇が 2,782R**。全買い目 20,150点／100円均等。

### 4.1 事後の類型別成績（因果ではなく「起きたことの家計簿」）

| 類型 | R数 | 点数 | 的中率 | **回収率** | 95%CI | 中央配当 |
|---|---:|---:|---:|---:|---|---:|
| 1号艇1着（的中側） | 1,676 | 12,142 | 49.5% | **97.1%** | [88.3, 107.4] | 960 |
| **C 進入負け** | **22** | 136 | **0.0%** | **0.0%** | [0.0, 0.0] | — |
| **B 1号艇消滅** | **28** | 202 | 3.6% | **3.3%** | [0.0, 12.6] | 660 |
| D 出遅れ | 270 | 1,970 | 4.1% | 42.3% | [8.6, 102.9] | 4,280 |
| E 差され | 254 | 1,823 | 8.3% | 48.8% | [26.1, 73.6] | 3,590 |
| F まくり | 398 | 2,897 | 5.3% | 24.9% | [13.7, 37.3] | 3,010 |
| G 大外強襲 | 133 | 972 | 3.0% | 20.7% | [2.3, 44.4] | 6,050 |
| **合計** | **2,782** | **20,150** | 31.9% | **71.7%** | — | 1,000 |

**本命tierだけで見ると、敗戦した全類型で的中ゼロ・ROI 0.0%**（本命は例外なく1号艇1着固定のため）。
上表の残存ROIはすべて抑え・穴・その他が拾ったもの。

読み取り：

> **C（進入負け）と B（消滅）だけが「買い目が全滅する」類型**である。
> 1号艇が1コースに入れなければ、抑えも穴も1号艇を絡めているので同時に死ぬ。
> 対して差され・まくり・大外では、頭が違っても保険が20〜49%を拾い戻している。
> **つまり「全滅する類型」＝「見送るべき類型」の候補は、B と C の2つに絞られる。**

### 4.2 では B と C を見送れば儲かるのか → **天井が +1.2pt**

**完全予知（実際にその類型だったレースを100%事前に当てられると仮定）**して見送った場合：

| 見送る対象 | 残るR数 | ROI | 改善 |
|---|---:|---:|---:|
| 現行（見送りなし） | 2,782 | 71.7% | — |
| C 進入負けを全部 | 2,760 | 72.2% | +0.5pt |
| B 消滅を全部 | 2,754 | 72.4% | +0.7pt |
| **B + C を全部** | **2,732** | **72.9%** | **+1.2pt** |
| B + C + G 大外強襲 | 2,599 | 75.6% | +3.9pt |
| （参考）敗戦をすべて | 1,676 | 97.1% | +25.4pt |

**B+C を完全に予知できても +1.2pt。** 現実の予測力は §3.1 のとおり最高十分位で
C が 4.38%（基準1.00%）・B が 1.90%（基準1.03%）であり、この帯を丸ごと見送っても
拾える真陽性は該当レースの一部にすぎず、同時に大量の1号艇1着レース（ROI 97.1%）を捨てる。
**期待値は確実にマイナスになる。**

> 頭替えの是非を測る専用指標を作る必要はなく、既に P(1号艇1着) を測っている

## 7. 結論

### 7.1 買い目を変える／見送るべき類型はあるか → **無い**

| 候補 | なぜ候補になったか | なぜ却下されるか |
|---|---|---|
| C 進入負け | 買い目が完全に全滅（22R・的中0・ROI 0.0%）。しかも敗戦内 AUC 0.754 と最も読める | **発生率が敗戦の2.15%（全体の0.98%）しかない。完全予知でも +0.5pt** |
| B 1号艇消滅 | 同じく全滅（28R・ROI 3.3%） | **同 2.31%。完全予知でも +0.7pt。予測力も AUC 0.671 と弱い** |
| B+C 合算 | 上記の合算 | **完全予知の天井が +1.2pt。現実の予測力ではこれを下回り、同時に ROI 97.1% の1号艇1着レースを大量に巻き添えにする** |
| G 大外強襲 | 見送れば +3.9pt と最大 | **最も読めない類型（敗戦内 AUC 0.567）。到達不能** |
| D 出遅れ / E 差され / F まくり | 母数が大きい | **敗戦内 AUC 0.55〜0.60 でほぼ判別不能。かつ全滅せず20〜49%残るので見送りの旨味も小さい** |

### 7.2 買い目の構成を変えるべき類型はあるか → **無い**

反実仮想シミュレーション（§5.2、40セル・各n≈5,577R）で、
**95%CI下限が控除率75%を超える構成×帯の組み合わせはゼロ**。
最危険帯で頭を2号艇に替える戦略も **+0.94pt / t=0.98** で有意でない。

### 7.3 では何が言えるのか（実装に持っていける唯一のもの）

**「頭を1号艇から替える」判断のゲートを、P(1号艇1着) の軸に載せ替えること。**

- 現行の374Rの頭替えは、頭的中率 10.5%（T1）〜46.0%（T3）の帯にまたがって**ほぼ無差別に発火している**
- gap・confidence・is_rough は頭替えの成否に対して t≈0 の無情報（§6.2）
- 一方、**前回調査で既に構築済みの P(1号艇1着) モデル**がそのまま使える（§6.3で4群が単調に並ぶことを確認済み）
- **ただし期待できるのはROIではない**。T1の124Rで頭替えを止めても全体ROIへの寄与は約 +0.6pt（§6.5）
- **効果は「的中率」と「予想の説得力」であって「妙味」ではない**。
  『1号艇が66.9%勝つレースで印を外していた』のを止める、という**予想の質の話**として扱うべき

`docs/roadmap_2026-08.md` の **P1-5（頭の散らし）** に対しては、
「散らす方向を広げる」のではなく **「散らすべきでない帯で散らすのをやめる」**が先、というのが本稿の示唆である。

### 7.4 やらなくてよいことの追加

| 項目 | 理由 |
|---|---|
| 負け方の類型を予測して2着・3着の構成を切り替える | 敗戦内 AUC 0.554〜0.567。差され/まくり/大外は判別できない（§3.2） |
| 進入負け・事故を理由にした見送りルール | 完全予知でも +1.2pt（§4.2） |
| `is_rough` を頭替えの判断に使う | 頭替えレースで t=−0.20、ROIも 47.7% vs 62.0% と逆方向（§6.2, §6.5） |
| `w1_late`（出遅れ率）を新規指標として実装 | 効くのは B（発生率1%）の予測のみ。既存の平均STと相関し、独立寄与が小さい |
| 頭=5号艇/6号艇の成績差を根拠にした調整 | n=30 / n=19（§6.1） |

1. **予想payloadは3,156R（58日分）しかない。** 類型別のセルは n=22〜398 で、
   §4.1 のROIの信頼区間は非常に広い（例: D 出遅れ 42.3% の CI は [8.6, 102.9]）。
   頭≠1号艇はさらに小さく n=374、頭別では n=19〜138。
2. **オッズが永続化されていない。** §5 のシミュレーションは
   「勝ち組み合わせの払戻が分かる」ことに依存しており、**実現ROIは厳密だが期待値（EV）は計算できない**。
   「モデル確率とオッズの乖離」を突く調査は依然として不可能。
3. **B（消滅）の内訳が分からない。** F・失格・転覆・エンストを区別できないため、
   「F持ち選手」のような実務上重要な情報は本データからは復元できない。
   `fetch_results.py:65` の `RE_RANK` を `Ｆ`／`失` にも対応させれば取得できる可能性がある
   （**本稿では一切のコード変更を行っていない**）。
4. **D（出遅れ）の閾値は恣意的。** 0.06〜0.15 で割合が 45.6%〜9.2% と動く（§3.4）。
   E:F:G の比は安定しているが、Dの絶対値を単独で引用しないこと。
5. **`race_no` の符号が群によって反転する**（§6.2 で頭≠1号艇では当たり6.30 < 外れ7.68、
   §6.3 の他指標とは逆向き）。選択バイアスの可能性が高く、解釈していない。
6. `data/venues/venue_characteristics.json` は**存在を確認した**（前回調査 §6.0 の懸念は解消済み）。
   ただし本稿はこのファイルを使っていない（会場効果は結果CSVから直接推定した）。
