# boat - ボートレース予想エンジン

## プロダクト概要

過去1年分の競走成績データ（全国・当地）と当日の出走表・展示データを組み合わせ、各選手にスコアを付けて着順を予測するシステム。

出力は HTML レポートを基本とし、1レースごとに以下の順序で確認できる：
1. 実データ
2. コメント / 展示情報
3. 予算別買い目
4. システム計算ロジック

WordPress 連携により、予想結果を公開ブログ `https://ask11.jp/web/boat/` に自動配信している。

## ユーザー

- 競艇ファン（自分の予想を検証したい人）
- データ派の投票者（根拠と計算ロジックを見たい人）

## ブランドトーン

- **データドリブン**：感覚や精神論ではなく数値・統計・確率ベース
- **透明性**：計算ロジックを隠さず開示
- **硬派だが読みやすい**：競艇専門用語は使いつつ、初見でも流れが追える構成
- **実用重視**：装飾より情報密度を優先

## ビジュアルの特徴

- 公開URL: `https://ask11.jp/web/boat/`
- 水のイメージ（ブルー系）を基調とする
- 表組みが多い（成績データ・買い目・確率）
- 会場・グレード・選手の階層構造を明確に示す

## 主要な画面

| 画面 | 用途 |
|---|---|
| 予想ページ（forecast-day） | 1日1会場分の予想詳細 |
| アーカイブ（archive） | 過去予想の日別/会場別一覧 |
| レビュー（review） | 予想と結果の突合・的中率検証 |
