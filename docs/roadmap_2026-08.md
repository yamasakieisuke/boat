### P1-5 について（2026-08-17 方針転換）

「頭を1号艇から散らす」を本丸としていたが、2件の調査で**否定された**。

- 頭を替えても的中は上がらない。現状88%はほぼ理論最適値（`race_development_research.md`）
- 事前情報で1号艇1着を AUC 0.698 まで当てられるが、**3連単ROIは全十分位で約70%に張り付く**
- 反実仮想シミュレーション（test 27,889R・40セル）で、**95%CI下限が控除率75%を超えるセルはゼロ**。
  最危険帯で頭を2号艇に替えても +0.94pt / t=0.98（`inside_loss_taxonomy.md`）

**残る唯一の実用的な余地**: 頭替え374Rの下位1/3（124R）は**1号艇が実際には66.9%勝つ帯**で
発火している。つまり**替えるべきでない場面で替えている**。ここを止めるのが先。
ただし効果は的中率と記事の説得力であって、**回収率ではない**。

さらに重要な発見として、**エンジン自身の指標（gap / confidence / is_rough）は
頭替えの成否に完全に無情報**（t = −0.08 / −0.71 / −0.20）。判断材料を持たずに
替えているのが実態。

蓄積待ちの判定は **2026-09-05 以降**に実施する（v5.24適用から約3週間）。

## 番組（レース編成）の意図を読む — 未着手（2026-08-18 起票）

### 問い（ユーザー提起）

1. **番組編成の意図は読み取れるか、読めたら予測は変わるか。**
   6枠に強い選手を入れる日がある、A1を3枠に入れる、など**日による偏り**があるはず。
   その意図（＝主催者がどういうレースにしたいか）を読み取れれば予測が変わるのではないか
2. **番組が自由に組めない準優勝戦・優勝戦は内枠有利なはず。** これは正しいか

### 予備確認（2026-08-18・完走6艇72,117R）→ 仮説2は強く支持される

| 種別 | n | 1号艇1着率 |
|---|---:|---:|
| 準優勝戦 | 3,058 | **73.0%** |
| 優勝戦 | 1,100 | **69.4%** |
| 一般 | 15,767 | 56.1% |
| 予選 | 34,626 | **48.4%** |
| 全体 | 72,117 | 55.2% |

**準優勝戦と予選で24.6ptの差。** 得点率で枠が決まる（番組を組めない）ほどインが強い。

### 既存実装との突き合わせ（要検証）

`predictor.RACE_TYPE_BONUS` は course_advantage への乗数として
`finalist=1.12 / general=1.00 / qualifier=0.87 / fixed_entry=1.20(v5.25で追加)`。

- **予選 48.4% / 全体 55.2% = 0.877** → qualifier の 0.87 はよく合っている
- **優勝戦 1.257 / 準優勝戦 1.322** に対し finalist は **1.12**。→ **過小の疑い**
- しかも**準優勝戦(73.0%) > 優勝戦(69.4%)** なのに、コードは両方 finalist で同じ扱い

※ 乗数は course_advantage に掛かるので勝率比と直接は比較できない。要実測A/B

### 調べるべきこと

- 番組編成の偏りを**事前に観測可能な形**で定量化できるか（例: 枠ごとの級別配置、
  1号艇と他艇の勝率差、A1が外枠にいる日 など）。`data/racecards/` が要る
  → **racecards再取得が完了していることが前提**（2026-08-18時点で進行中）
- その偏りが**オッズに織り込まれていないか**を確認する。今回の一連の分析で
  「公開データは全部織り込まれている」ことが繰り返し確認されているので、
  **番組の偏りも織り込まれている可能性が高い**。ただし番組意図は解釈が要る情報なので
  参照者が少ない可能性はある（福岡オリジナル展示と同じ理屈）
- 準優/優勝戦の finalist 乗数を分離・再較正すべきか

### 目的との関係

**この検証は「展開を読んで当てる」という目的に直結する。** 番組意図＝主催者が仕込んだ展開
であり、それを読むのは定番出目を買うのとは正反対の行為。
**回収率に効かなくても、非定番出目での的中が増えるなら目的には適う。**
